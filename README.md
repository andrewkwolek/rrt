# RRT
Author: Andrew Kwolek

Generates an RRT animation that navigates from a start point to an end point through obstacles. All instances are randomly generated resulting in a different path and environment on every run. Try it out!

## Quickstart
1. Clone repo.
2. Run `python3 main.py`
